# Paper

This directory holds the IEEE conference paper (`\documentclass[conference]{IEEEtran}`)
that reports both studies in this repository: *Depth and Freshness, Not
Learned Prediction: A Pre-Registered Study of Prefetching from Disk Blocks to
Product Pages*, by Ashvik Mishra (24BAI0342) and Shourya Saraf (24BDS0391),
School of Computer Science and Engineering, Vellore Institute of Technology,
Vellore. The e-mail addresses are left out on purpose; `main.tex` has a
comment where they go.

**No LaTeX toolchain is installed on the development machine, and none can be
installed (MASTER_PLAN L6).** The paper is compiled on Overleaf. Locally, the
gate is `paper/check.py`, a structural lint that stands in for a compile.

## Layout

| path | what | written by |
|---|---|---|
| `main.tex` | preamble, title, author blocks, `\input` of every section | WP7, final form WP14 |
| `sections/*.tex` | one file per section, written from the results (WP14); `appendix.tex` comes after the references | WP7, then WP14 |
| `refs.bib` | the verified bibliography (see `docs/REFERENCES.md`) | WP7 |
| `numbers.tex` | one `\newcommand` per number quoted in the prose | generated by `numbers.py` (WP13, WP14) |
| `tables/*.tex` | IEEE `tabular` tables, `\hline` only (no booktabs) | generated by `tables/make_tables.py` (WP13, WP14) |
| `figures/*.pdf` | vector figures at IEEE column or text width | generated by `figures/make_figures.py` (WP13, WP14) |
| `decisions.py` | the pre-registered decision rules of `results/*/PREREGISTERED.md`, applied to the results; feeds the `\dec...` macros and the decision table `tables/t9_decisions.tex` | WP14 |
| `genlib.py` | what the generators share: reading `results/` through the schemas, provenance hashes, LaTeX number formats, macro names | WP13 |
| `*manifest.json` | per generated file, every input with its SHA-256 and whether it matches the study's `provenance.json` | generated |
| `check.py` | the structural lint | WP7, WP14 |

The generators read only `results/**`. When an input is missing, a generator
writes a placeholder stamped "MISSING: <file>", so the paper always builds.

## Building it

1. Regenerate the numbers, tables and figures from the committed results.
   This runs no experiment and takes under a minute:

   ```bash
   PYTHONPATH=src .venv/bin/python reproduce.py paper
   ```

   `reproduce.py paper --fixtures` builds the same outputs from the synthetic
   tree in `tests/fixtures/results/` into `outputs/paper-fixture/` (never into
   `paper/`); everything it writes is stamped FIXTURE DATA. The generators load
   `genlib.py` and `decisions.py` by file path and must never be run with
   `paper/` on `sys.path`, because `numbers.py` would shadow the standard
   library's `numbers` module.

2. Run the lint:

   ```bash
   python3 paper/check.py            # skeleton: a not-yet-generated file is a warning
   python3 paper/check.py --strict   # after step 1: generated files and \ref labels must exist
   python3 paper/check.py --final    # submission gate: --strict, no \todo, no missing result
   ```

   It exits with status 1 on any error. It runs under system `python3`, since it
   uses only the standard library.

3. On Overleaf (the compile note):
   - Create a blank project and upload the **contents** of `paper/`:
     `main.tex`, `refs.bib`, `numbers.tex`, `sections/`, `tables/` and
     `figures/` (the `.py` and `.json` files are not needed there).
   - Menu: Compiler **pdfLaTeX**, Main document **`main.tex`**, TeX Live
     2023 or later. `IEEEtran.cls` and `IEEEtran.bst` ship with Overleaf's TeX
     Live; BibTeX runs automatically. Recompile twice after the first run so
     the cross-references and the bibliography settle.
   - `numbers.tex` defines about 21,600 macros (about 1.9 MB). That is well
     inside TeX Live's default memory (string pool and main memory), and
     `tests/test_paper_decisions.py` keeps it below 30,000 macros and 2.5 MB.
     If a future results set pushes it over, trim a family in
     `numbers.FAMILIES` (the delta, comparison and table filters at the top
     of each family say what is kept).
   - Expected warnings: none from undefined references or citations;
     `check.py --final` guarantees every `\ref`, `\cite` and number macro
     resolves. Overfull boxes are possible in the widest generated tables;
     the generators set `\scriptsize` and a 2 pt column gap on the dense
     ones, sized against the 7.16 in text width by estimate only (no local
     compile, MASTER_PLAN L6).

## Length

The body targets 8 IEEE pages including figures and tables, with the
references and the appendix (the full decision record `tab:t9_decisions`,
and the supplementary tables and figures) extra (MASTER_PLAN L4). With no compiler
the length is estimated, not measured: about 5,500 words of body text with
every number macro expanded (about 4.6 pages at 1,200 words per two-column
page, plus about 0.5 page of headings, lists and paragraph breaks), about 2.7
pages of floats (the dataset, disk, real-device, web and live tables, and
Figs. F1, F3, F5 and F8) and 0.2
page for the title block: about 8.0 pages, with an uncertainty of about half
a page. If Overleaf shows more than 8 pages, move the schematic (F1) and then
the web decomposition table (`t5_web_decomposition`) to the appendix, in that
order.

Every path the paper references must lie inside `paper/`, since Overleaf only
receives this directory. `check.py` rejects any path that leaves it.

## Rules for the text

- **No number is typed by hand into `sections/*.tex`.** Every number in the
  prose comes from a `numbers.tex` macro, and every table and figure comes from
  a generator. `check.py` fails if it finds a decimal, a percentage (`\%`),
  percentage points (`pp`), a multiplier (`x`, `\times`), a ratio such as
  `52/56`, or a thousands-grouped count outside its allow-list. The allow-list
  covers software and kernel versions, section and decision numbers, and
  LaTeX lengths. Extend `ALLOW_PATTERNS` only under review.
- Every `\cite` key must be in `refs.bib`. To add a reference, follow the
  procedure in `docs/REFERENCES.md`.
- Write `_` as `\_` outside math. Overleaf rejects a bare underscore, and
  `check.py` reports one.
- The honesty constraints in MASTER_PLAN §5 apply to every sentence:
  - label every number as simulated or measured
  - make no classifier-accuracy claim on real traces
  - compare against the strongest fair baseline
  - give each number its n, CI and seeds
- State a finding only in the words its pre-registered rule gives. The
  verdicts are generated (`\dec<Key>Verdict`, from `decisions.py`), and
  `tests/test_paper_decisions.py` pins every verdict the prose relies on, so
  a change in the results that changes a verdict fails the suite until the
  prose is rewritten.
- The page target is 8 IEEE pages including figures, with references extra.
  Material that does not fit goes in `sections/appendix.tex`, after the
  references (MASTER_PLAN L4).
