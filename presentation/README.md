# Presentation

The presentation material is [`docs/PRESENTATION.md`](../docs/PRESENTATION.md):
a slide-by-slide outline and viva preparation. A Beamer deck,
`presentation/slides.tex`, will reuse the paper's generated figures
(`paper/figures/*.pdf`) and is compiled on Overleaf with the same toolchain as
the paper; it does not exist yet.

The two Review 2 `.pptx` decks were removed from `master`: they carried
pre-fix numbers (the old ~7% LSTM hit-ratio rows and the "7.3x faster
inference" claim). They remain in git history, last present at commit
`66226bb`. No `.pptx` is generated here because `python-pptx` is not
available in this environment.

Do not hand-edit numbers into slides. Every number comes from `results/`,
regenerated by `python reproduce.py`.
