The full seven-mode comparison (including both strided variants and explicit
LSTM skip rows) is generated by the benchmark command. Adaptive had the
highest hit ratio on each of the three generated traces, but Markov had lower
*modelled* mean cost in those runs because prefetching is charged. On the
bundled 1,000-request MSR-format sample, fixed sequential had the highest hit
ratio, while no prefetch had the lowest modelled mean cost among the listed
modes. That sample's source provenance has not been verified.

The drift report showed zero-window switch lag and 100% phase accuracy for
both frozen and labelled-online classifiers on all four easy generated phases.
This **does not demonstrate faster adaptation**. A more challenging drift
scenario and independently labelled data would be needed for that claim.

The optional LSTM row was skipped because no trained PyTorch artifact was
available. Its code path is implemented but has not been runtime-validated in
this environment. No full IOTTA trace was supplied, so no IOTTA benchmark or
general real-workload outcome can be claimed. The existing Review 2 slide
deck contains pre-Stage-2 measurements; refresh its tables from a current
benchmark before presenting them.
